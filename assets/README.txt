Forest assets
- Models, ground textures, HDRI: Poly Haven (polyhaven.com), CC0 public domain.
  fir_tree_01, fir_sapling_medium, fern_02, rock_moss_set_01/02, tree_stump_01/02,
  dead_tree_trunk, pine_roots, dry_branches_medium_01, forest_ground_04, forest_leaves_04, misty_pines.

- More Poly Haven (CC0): shrub_02/03/04, nettle_plant, weed_plant_02, dandelion_01, grass_ground, aerial_grass_rock.
- Grass: procedural GPU blades (grass.js), no asset.
